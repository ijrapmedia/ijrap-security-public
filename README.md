## Why IJRAP Security Exists
Designed to counter deepfakes, metadata tampering, and hostile field conditions (zero-internet, risk of seizure), **IJRAP Security** transforms standard devices into tamper-proof evidence vaults by uniting investigative reporting with forensic science.

## Core Technical Capabilities
- **4-Pillar Evidence Sealing:** Binds live audio, video, photo, and written testimony (with GPS and UTC timestamps) into a single cryptographic block.
- **Hybrid Post-Quantum Cryptography:** Uses classical SHA-256 and quantum-resistant SHA-3-256 (Keccak-256) hashing.
- **WORM Immutability:** Locks files in read-only mode (`0o444`) immediately upon capture to prevent alterations.
- **Offline-First Resilience:** Operates without reliance on commercial cloud providers.
